# Toko Bangunan - Company Profile Website

Website company profile modern untuk toko bangunan "TB. Maju Jaya" dengan nuansa Kuning/Hitam.

## Struktur Project

- `index.html`: File utama halaman website.
- `style.css`: File styling dan animasi.
- `script.js`: File logika untuk menu dan animasi scroll.
- `assets/`: Folder gambar (generated placeholders).

## Cara Menjalankan

Project ini adalah static website, jadi sangat mudah dijalankan:

1.  **Cara Paling Mudah**:
    - Buka folder project ini.
    - Double click pada file `index.html`.
    - Website akan terbuka di browser default Anda.

2.  **Menggunakan VS Code Live Server** (Rekomendasi):
    - Buka folder ini di VS Code.
    - Install extension "Live Server".
    - Klik kanan pada `index.html` -> "Open with Live Server".
    - Ini akan menjalankan local server dan auto-refresh jika ada perubahan code.

## Fitur

- **Responsive Design**: Tampil rapi di Mobile dan Desktop.
- **Modern UI**: Warna primary #FFC300 dengan nuansa dark.
- **Animasi**: Efek fade-in halus saat scroll.
- **Bagian Lengkap**: Header, Hero, Tentang, Produk, Keunggulan, Galeri, Kontak.
